# Acknowledgments

Attention Deck is an independent implementation built on the official Elgato Stream Deck SDK and the documented Codex app-server protocol.

The architecture and safety model were informed by these open-source projects:

- [Elgato Stream Deck SDK and samples](https://github.com/elgatosf/streamdeck)
- [agentsd](https://github.com/paultyng/agentsd)
- [yolodeck](https://github.com/cruftbox/yolodeck)
- [Codex Control for Stream Deck](https://github.com/emollick/codex-stream-deck)
- [OpenAI's Node app-server client](https://github.com/openai/codex-plugin-cc/blob/main/plugins/codex/scripts/lib/app-server.mjs)

No source code or visual assets from those reference projects are included verbatim. Runtime dependency notices for bundled software are preserved in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
